# BeeHouse Official UI Refresh V6

This build is intentionally based on the original working project because the previous UI refresh altered core Admin JavaScript. V6 restores the original runtime files and only adds targeted Admin application-review UI/functionality.

## GitHub Pages
Upload the contents of this ZIP to the repository root. No Node build step is required.

## Important
The project still uses localStorage for CMS/application data, so GitHub Pages does not provide a shared database between different browsers/devices.
