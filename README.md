# BeeHouse GitHub Pages – Interviewer Center

## เพิ่มในเวอร์ชันนี้
- เพิ่มบทบาท `interviewer` (ผู้สัมภาษณ์)
- Super Admin มีเมนู `บัญชีผู้ใช้` สำหรับเพิ่ม/แก้ไข/เปิด/ปิด/ลบบัญชีผู้สัมภาษณ์
- ผู้สัมภาษณ์เข้าสู่ระบบผ่าน `login.html` แล้วถูกส่งไป `interviewer-dashboard.html`
- ผู้สัมภาษณ์เข้าถึงเฉพาะใบสมัคร/ผลสัมภาษณ์และการให้คะแนน ไม่เข้าถึง CMS เว็บไซต์
- ผู้สัมภาษณ์มี heartbeat ทุก 10 วินาที และ Admin เห็นสถานะ “กำลังใช้งาน” ใน Dashboard/บัญชีผู้ใช้
- บันทึกชื่อผู้สัมภาษณ์และ username ลงในผลสัมภาษณ์

## ข้อจำกัดของ GitHub Pages
บัญชีที่สร้างจาก Admin และสถานะออนไลน์ถูกเก็บใน `localStorage` ของเบราว์เซอร์นั้น เพราะ GitHub Pages ไม่มีฐานข้อมูลกลางหรือ API เขียนข้อมูลจากเว็บได้ จึงเหมาะกับการทดสอบ/ใช้งานในเบราว์เซอร์เดียวกัน หากต้องการบัญชีที่ล็อกอินได้จากทุกเครื่องจริงและปลอดภัย ต้องใช้ Backend + Database + authentication server
